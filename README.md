# TelaLocal MVP

MVP SaaS B2B2C multi-tenant de mídia indoor (DOOH) para comércio local.

## Rotas
- `/` landing comercial
- `/cadastro` entrada de lojistas/anunciantes
- `/painel` dashboard demonstrativo
- `/player/demo` Web Player demonstrativo
